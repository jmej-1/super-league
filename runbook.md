# Super League: Weekly Runbook

Everything is generated by one script from plain data files. **Nothing is typed into the docs by hand except the short "notes" sections.** Run this every Tuesday after MNF.

## Where things live (all in this project)
- **Code:** `claude/pipeline/superleague.py` (builds every doc) and `claude/pipeline/ingest.py` (turns raw Sleeper JSON into the data files)
- **Data:** `claude/pipeline/data/*.txt`
  - `league.txt` (settings + names), `scoring.txt` (Sleeper scoring keys), `byes.txt`, `draft.txt`
  - `matchups.txt`, `transactions.txt`, `rosters.txt`, `players.txt` (every NFL player seen: name, pos, team, injury, years_exp)
  - `nfl_points.txt`: every active NFL player's real points each week in league scoring
  - `sleeper_proj_{w}.txt`: Sleeper's projections rescored in league scoring; `kicker_distance.txt`
  - Logs to grade next week: `teamproj_{w}.txt`, `lines_{w}.txt`
  - Claude's written notes: `notes_projections.txt`, `notes_power.txt`, `notes_lines.txt`
- **Output:** docs 3, 5, 7, 8, 10-20 are fully generated. Docs 1, 2, 4, 6, 9 are hand-maintained reference.

## Jesse's part (once a week, ~1 minute)
On his Mac: run `~/superleague/update.sh` in Terminal, then drag `superleague_data.zip` into the chat and say "update". (The script downloads league info, rosters, all matchups, all transactions, every week's NFL stats and Sleeper projections, and the players file.) Setup command is in the chat from Nov 11 and below.

## Claude's part
1. **Restore:** `project_read` both scripts and every data file into `pipeline/` and `pipeline/data/`.
2. **Ingest:** unzip Jesse's upload into its own folder and run `python3 -I ingest.py <unzipped>/data data`. It rescores stats and projections, and replaces matchups/transactions/rosters/players for the weeks present. Check that every rostered player's rescored points equal Sleeper's `players_points` (they did exactly on Nov 11: 1,215/1,215).
3. **Run:** `python3 superleague.py data out`. Check the printout (weeks, trades/vetoes, replacement levels, points-per-win, model RMSE/bias, line factor).
4. **Notes:** rewrite the 3 notes files so every claim matches the new numbers; rerun.
5. **Save:** every `out/*.md` to its doc; `out/teamproj_{next}.txt` and `out/lines_{next}.txt` plus all changed data files to `claude/pipeline/data/`.
6. **Hand docs:** 4-history-and-records if a record broke; 2-managers if needed.
7. **Tell Jesse** the headline changes, league-wide.

**update.sh** (saved to `~/superleague/update.sh` on Jesse's Mac):
```bash
#!/bin/bash
L=1395560684279836672; S=2026; A=https://api.sleeper.app/v1
D=~/superleague/data; rm -rf "$D"; mkdir -p "$D"; cd "$D" || exit 1
curl -s -o league.json $A/league/$L; curl -s -o users.json $A/league/$L/users
curl -s -o rosters.json $A/league/$L/rosters; curl -s -o drafts.json $A/league/$L/drafts
curl -s -o players.json $A/players/nfl; curl -s -o state.json $A/state/nfl
for w in $(seq 1 18); do
  curl -s -o matchups_$w.json $A/league/$L/matchups/$w; curl -s -o tx_$w.json $A/league/$L/transactions/$w
  curl -s -o stats_$w.json $A/stats/nfl/regular/$S/$w; curl -s -o proj_$w.json $A/projections/nfl/regular/$S/$w
done
cd ~/superleague && rm -f superleague_data.zip && zip -qr superleague_data.zip data && open -R ~/superleague/superleague_data.zip
```

## What's derived from data (never hardcode)
- Scores = sum of starters; pairings from matchup_id; remaining schedule from future matchup lines
- Trades and vetoes from the transaction log (veto = a commissioner move that exactly reverses a trade)
- Replacement levels (best 5 unrostered players per position, all NFL), points-per-win (from score SD), Pythagorean exponent, kicker FG distance
- Player projections = Sleeper projected stats rescored in league scoring; whether to blend in own 2026 production is re-tested every run (walk-forward; only used if >2% better). Uncertainty and the line factor are calibrated from the backtest each run
- Weekly awards use that week's position medians only, so past awards never change

## Model assumptions (in CONFIG at the top of the script; documented in the docs)
Extra Questionable/Doubtful discounts, Out-player return chance in later weeks, waiver-pickup rule (3rd-best FA, +3 pt gain, max 2/week), blend threshold (2%), replacement group size (5), sim count. Vegas is not applied separately because Sleeper's projections already use it.

## Key settings
- Half PPR, Pass TD 4, INT -2, fumble lost -2; K: FG 2 + 0.1/yd over 30, XP 0.5; DEF pts-allowed tiers 10/7/4/1/0/-1/-4
- Lineup QB, RB, RB, WR, WR, TE, FLEX (RB/WR/TE), K, DEF; 4 BN; 1 IR. FLEX is never its own position in any stat.
- 6-team playoffs Weeks 15-17, seeds 1-2 bye, PF tiebreaker, trade deadline Week 12. 70 regular-season games + 5 playoff games.

## Multi-season plan (when 2027 starts)
- Sleeper creates a new league ID each season (linked by `previous_league_id`). Keep each season's data in its own folder (`data/2026/`, `data/2027/`, …) and run the pipeline per season.
- Season-dependent values (points-per-win, replacement levels, Pythagorean exponent, projection tuning) are computed **per season**, since the league landscape changes year to year.
- Add an all-time layer on top: career records, all-time H2H, titles, all-time WAR/MVP, draft and trade history across years.
- Once there are 2+ seasons, fit the CONFIG assumptions (Vegas elasticity, injury discounts, waiver rule) from history instead of choosing them, and use prior seasons as the preseason baseline for early-week projections.
